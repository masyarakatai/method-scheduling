# Behavior note 19: screen block 3a, menus, designers, preferences (real app)

Source: our own checks in the real reference app, 2026-10-12, a short background block on
`ZTEST Lantern Creek` (the owner was on a call; menus and dialogs only, no edits saved).
Clean-room: behavior in our own words, no copied text, no screenshots kept.
This note outranks notes 01 to 18 wherever they disagree.

## Menus (A1, A18, A25)

- The app menu has Settings; File has New, New from Template, Open, Open Shared, Open
  Recent, the vendor's cloud backup, Save, Save As, Save as Template, Share, Import Script,
  two exports in the vendor's closed formats, and Close Active Schedule. **Import Script is
  the only open-format import in the menus.**
- Edit: Undo, Redo, Cut, Copy, Paste, Advanced Find and Replace, Select All.
- View: full screen only. Schedule: one item per tab plus Manage Flag Types.
- Design: Breakdown Designer, Board Strip Designer, Calendar Strip Designer, Production
  Info, New Report (based on any of eleven report kinds; red flags is not one).
- Window: Minimize, Zoom, Close Window, Close All. Help: User Manual, Support, Keyboard
  Shortcuts.
- Key equivalents could not be read in the background; E-K1 stays open.

## Preferences (CAL-03)

- Settings holds date preferences only: a date format (month, day, year by default) and the
  week's start day (Sunday by default). They are **app-wide, not per schedule**, as ours.

## Production info (RPT-13)

- A dialog in the Design menu holds: title, company, director, producer, unit production
  manager, assistant director, art director, set dresser, script date, production number,
  preparer, timing, episode, and four free fields. All are text.

## Report designer (RPT-14, RPT-15)

- A report has a name, a strip layout picked from the layout list, a strip type, and
  switches for banners, shoot day strips, strip colors, red flags, conflicts and the total
  strip count; a page break choice; a day break choice (all, or fewer); an element
  category picker; and the full strip designer.
- A second tab designs **the report header**: a named header layout, include header on or
  off, first page only, bold, italic, alignment and font size, and fields placed in rows
  from a list: space, custom text, the report name, today's date, board, sub-board, the
  start date, and every production info field.
- Export from the Reports tab offers PDF and Excel; the date range (from, to) sits in the
  Reports toolbar.

## Breakdown designer (BRK-03)

- The sheet's header fields sit in a grid of rows with set widths; fields can be moved and
  removed by dragging them to a "remove" area, and added back from it. Fields: episode,
  scenes, I/E, set, time of day, shoot time, synopsis, location, page eighths, script pages,
  script day, screen time, unit, sequence, comments, sunrise, sunset. No sheet number field.

## Calendar strip designer (CAL-08, E-C11)

- Part of the schedule (Design menu), not a user preference. Default fields: scene
  number, set, elements, and cast IDs; alignment; the same field list as the board's strip
  designer.

## Day out of days sort (DOD-12, DOD-13, E-D25)

- Up to four keys, each a field and an order, with Clear, Cancel and Sort. Fields: board
  ID, element name, first working day, last working day, worked days, held days.

## Not reachable in the background

- Choosing a report in the Reports list and the board toolbar icons ignored background
  clicks; those wait for a full-screen block.
